# Módulo 04 - Técnicas de Testes

Exercício desenvolvido durante o curso de Engenharia de Qualidade de Software da EBAC.

## Conteúdo

Aplicação prática de técnicas de teste de software, incluindo:

- Particionamento de Equivalência
- Análise de Valor Limite
- Tabela de Decisão
- Validação de regras de negócio
- Cenários válidos e inválidos
