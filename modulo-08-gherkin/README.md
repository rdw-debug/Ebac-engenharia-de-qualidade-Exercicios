# Módulo 08 - Gherkin

Exercício desenvolvido durante o curso de Engenharia de Qualidade de Software da EBAC.

## Conteúdo

Criação de cenários de teste utilizando Gherkin e conceitos de BDD.

Foram trabalhados cenários relacionados a:

- Cadastro de cliente
- Configuração de produtos
- Campos obrigatórios
- Validação de e-mail
- Limite de quantidade de produtos
- Limpeza de configurações
- Escrita declarativa utilizando Dado, Quando e Então
