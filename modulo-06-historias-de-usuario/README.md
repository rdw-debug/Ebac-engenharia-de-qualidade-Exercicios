# Módulo 06 - Histórias de Usuário

Exercício desenvolvido durante o curso de Engenharia de Qualidade de Software da EBAC.

## Conteúdo

Atividade prática de criação e análise de histórias de usuário para a EBAC-SHOP.

Foram trabalhados cenários relacionados a:

- Adição de produtos ao carrinho
- Login na plataforma
- Lista de desejos / favoritos
- Critérios de aceitação
- Regras de comportamento do usuário
